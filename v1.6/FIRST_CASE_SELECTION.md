# 第一套 Skill 验收案例：2021 D

## 结论

锁定 `gmcm-2021-D` 作为第一套真实验收案例。

## 为什么选它

1. 原题与结构化数据完整。
2. 优秀论文数量足够做至少两篇横向比较。
3. 四问覆盖不同建模范式，而不是只测一个算法。
4. 很适合强制回答“为什么选、为什么不选”。
5. 可以实际运行代码，而不是停留在读论文。
6. 来源题名冲突可测试证据治理。

## 第一轮验收顺序

### Phase A：资料落盘
- 题面
- 4个 Excel
- 选2篇方法差异明显的优秀论文
- 可选1份公开代码/解析

### Phase B：learn
不看优秀论文答案，先由 Skill：
- 逐问拆解
- 建立候选模型矩阵
- 给推荐路线和切换条件

### Phase C：paper-review
逐问精读两篇优秀论文：
- 作者做法
- 证据
- 假设
- 模型
- 验证
- 风险
- 我们的判断

### Phase D：replication
实际运行/重写关键代码：
- 特征选择
- Q2回归
- Q3分类
- Q4解释/优化

未运行不得标记 verified。

### Phase E：practice
把答案隐藏，让学习者自己完成至少一问的：
- 数学结构
- 候选模型
- 推荐路线
- 验证方案

### Phase F：review
沉淀：
- 方法卡
- 题型卡
- 错误模式
- 下一题选择规则

## v0.5 是否通过的判据

只有当这套案例能做到以下几点，才升级：
- 同一问题能比较至少3条合理路线；
- 能明确说明排除理由；
- 能追溯优秀论文主张；
- 能把复现状态与作者主张分开；
- 能在新会话读取 learning_state 恢复；
- 能产生真正可复用的方法卡而非题目摘要。
