# 2021 D Risk Checklist

## Q1
- [ ] 特征选择是否完全在训练折内？
- [ ] 是否删除常量/近零方差变量？
- [ ] 是否检查高度相关变量冗余？
- [ ] 是否比较线性与非线性重要度？
- [ ] Top20 是否做过稳定性检验？
- [ ] 是否避免用 test 集参与筛选？

## Q2
- [ ] 是否优先建模 pIC50？
- [ ] 是否验证 IC50↔pIC50 单位转换？
- [ ] 所有候选模型是否使用同一数据切分？
- [ ] 超参数是否仅在内层CV选择？
- [ ] 是否报告 MAE/RMSE/R² 和波动？
- [ ] 是否检查外推风险？

## Q3
- [ ] 五个标签是否分别统计类别比例？
- [ ] 是否没有把 Accuracy 当唯一指标？
- [ ] SMOTE/过采样是否只在训练折内部？
- [ ] 特征筛选是否只在训练折内部？
- [ ] 五个标签是否允许选择不同模型？
- [ ] 是否报告 PR-AUC/MCC 等不平衡指标？
- [ ] 若 Q4 使用概率，是否做概率校准？

## Q4
- [ ] 是否明确 favorable 标签映射？
- [ ] 是否单独处理 CYP3A4 语义歧义？
- [ ] 是否区分“预测好”与“真实药理可实现”？
- [ ] 描述符是否被错误当成相互独立的决策变量？
- [ ] 是否定义训练数据支撑域/可行域？
- [ ] 区间是否有 bootstrap/stability 证据？
- [ ] 若用 PSO/GA/NSGA，是否说明它只是求解器？
- [ ] 是否避免把模型空间最优点称为可合成新分子？
