# First Case Selection

## 首个验收案例选择标准

每项 0-5 分：

1. 原题完整性
2. 官方附件完整性
3. 优秀论文数量
4. 可复现性
5. 模型路线多样性
6. 是否能测试“为什么选/不选”
7. 是否能测试验证与风险
8. 是否适合形成方法卡/题型卡
9. 对初学者的教学价值
10. 资料来源可追溯性

## 当前首选：2021 D 候选药物优化建模

选择理由：

- 镜像目录有题面与 4 份 Excel 数据；
- 优秀论文 D 目录至少有 5 篇 PDF；
- 数据规模允许在普通 Python 环境中复现；
- 四问覆盖：
  - 高维特征选择
  - 回归预测
  - 多个分类模型
  - 条件/优化与解释
- 非常适合比较：
  - Pearson/Spearman/互信息/树模型重要性/LASSO 等特征选择
  - 线性/PLS/随机森林/GBDT/XGBoost/SVR 等回归
  - 逻辑回归/随机森林/Boosting/SVM/神经网络等分类
  - 规则抽取、可解释模型、Pareto/约束搜索等问题4路线
- 存在真实来源标题冲突，可直接测试 source governance。

## 为什么暂不把 2023 A 作为第一题

2023 A 也有多篇优秀论文，但当前公开题目目录中未观察到类似 2021 D 那样完整、直接的结构化附件组合。它更适合第二阶段测试通信机理/仿真类问题。

## 为什么暂不把 2023 B 作为第一题

2023 B 有官方比赛期间目标函数位置调整的历史，适合测试题面更正和数学推导，但数学专门性更高，不适合作为整个学习 Skill 的第一轮验收。

## 为什么 2024 C 放到后面

2024 C 的数据驱动磁芯损耗建模很适合作为第二/第三套验收题，但当前公开 GitHub 侧的优秀论文没有像 2021-2023 一样直接按 A-F 完整落在仓库中，论文获取与核验成本更高。

## 锁定条件

2021 D 可作为首个 v0.5 验收案例，但开始全文精读前仍需：

1. 将题面和 4 个附件实际落盘；
2. 至少选择 2 篇优秀论文落盘；
3. 比较论文使用的方法是否足够不同；
4. 有代码时只作为额外第三来源；
5. 第一轮先不依赖“该论文一等奖”这一标签。
