# 2021 D Reference Baseline v0.7

> 状态：`CONTAMINATED_REFERENCE_BASELINE`
>
> 本文件用于定义“一个方向正确的学习型解题基线”，不计入真正 Blind Eval 分数。
> 原因：生成本文件的当前研发会话已经接触过优秀论文方法信息。

## 0. 先做的问题结构识别

这不是一道“找一个最强机器学习模型”的题，而是四个连续但不同的数学任务：

1. Q1：高维监督式特征选择与重要度稳定性
2. Q2：小中样本表格数据的 QSAR 回归
3. Q3：五个相关但标签分布、难度与语义不同的二分类任务
4. Q4：在预测模型基础上的可解释可行域识别 / 多目标约束决策

四问共享数据，但不能默认共享同一个模型。

# Q1：729 → 20 个描述符

## 真正要解决的数学问题

不是“谁和 pIC50 相关系数最大”，而是：

> 在高维、强冗余、可能非线性的描述符空间中，找出一组规模不超过20、对活性预测有稳定增益、彼此不过度冗余的变量。

## 候选路线

### 路线 A：单变量 Filter 基线
- Spearman
- Mutual Information
- 单变量回归分数

优点：快、解释直观。  
缺点：不能识别变量组合效应，容易挑出一批高度冗余变量。

### 路线 B：稀疏线性 Embedded
- LASSO / Elastic Net

优点：适合 729 维和共线性场景，结果可解释。  
缺点：主模型仍偏线性，若真实结构高度非线性会漏掉重要变量。

### 路线 C：非线性模型重要度
- ExtraTrees / Random Forest
- Gradient Boosting
- permutation importance

优点：能捕捉非线性和交互。  
缺点：树的重要度会受变量尺度、取值数、共线性影响，单独使用不稳。

### 推荐主路线：稳定性驱动的两阶段选择

1. **只在训练折内部**做预处理和特征筛选。
2. 删除：
   - 常量 / 近零方差变量；
   - 明显重复变量；
   - 极高相关成组变量中的冗余项。
3. 用两类互补证据排名：
   - Elastic Net：稀疏、稳定、线性/近线性证据；
   - permutation importance 或 mutual information：非线性证据。
4. 在重复交叉验证中记录每个变量进入 Top20 的频率。
5. 以“进入频率 + 验证性能 + 冗余惩罚”得到最终20个。

## 为什么不直接采用 PCA

PCA适合降维，但题目明确要求：

> 给出“前20个最具有显著影响的分子描述符”。

PCA输出的是主成分，不是原始描述符，因此不适合作为主答案；可作为性能对照。

## 为什么不直接用神经网络做特征筛选

1974 个样本相对有限，且题目要求解释“哪些描述符最重要”。深度网络的重要度需要额外解释方法，训练稳定性和竞赛时间成本都更高，没有先验优势。

## 验证

- outer CV 评价最终20变量的泛化性能；
- 与 5/10/15/20 个变量的性能曲线比较；
- bootstrap / repeated CV 检查 Top20 稳定度；
- 报告高度相关变量组，避免把“同一信息的多个版本”误当成多个独立重要因素。

# Q2：活性定量预测

## 目标变量

优先预测 `pIC50`。

理由：
- pIC50 与活性单调正相关；
- 对 IC50 的跨数量级分布进行对数压缩；
- 更适合一般 QSAR 回归。

若原数据 IC50 单位为 nM：

\[
pIC50 = -\log_{10}(IC50 \times 10^{-9})
      = 9-\log_{10}(IC50_{\mathrm{nM}})
\]

最终再反变换：

\[
IC50_{\mathrm{nM}}=10^{9-pIC50}
\]

必须先用训练表中的已知两列核对公式。

## 候选路线

### 基线：PLS / Elastic Net
适合：
- 小样本；
- 多重共线性；
- QSAR解释。

作用：
不是为了最终一定获胜，而是给复杂模型建立可靠基线。

### 候选 1：RBF-SVR
适合：
- 约2000样本；
- 20以内特征；
- 非线性平滑映射。

风险：
- 对 C、gamma、epsilon 敏感；
- 必须标准化。

### 候选 2：Gradient Boosting Family
- HistGradientBoosting
- XGBoost / LightGBM（环境允许时）

适合：
- 表格非线性；
- 特征尺度不敏感；
- 可以捕捉交互。

风险：
- 小数据时过拟合；
- 调参过多容易把 validation 当 test 使用。

### 候选 3：Random Forest / ExtraTrees
优点：
稳健、快速、可解释基线强。  
缺点：
回归外推能力较弱，平滑预测通常不如 boosting/SVR。

## 当前推荐

不在看到数据前宣布某一个算法必胜。

正式路线：

> `PLS/ElasticNet baseline`  
> vs `RBF-SVR`  
> vs `Gradient Boosting`  
> 在相同 outer CV 上竞争。

优先按：
1. RMSE
2. MAE
3. R²
4. repeated-CV 方差

综合选择。

若 SVR 与 boosting 差异很小，优先选解释更简单、调参更稳定的一方。

## 不推荐把 MLP 作为首选

样本只有 1974，最终变量最多20个；这是典型表格小样本，不存在必须使用深度学习的结构优势。

# Q3：五个 ADMET 分类器

## 先纠正一个常见思维错误

题目要求：

> 分别构建五个分类预测模型。

它并没有要求五个标签使用同一个算法。

因此正确策略是：

> 五个任务共享建模框架，但模型、阈值和不平衡处理可以不同。

## 候选路线

### 基线
Regularized Logistic Regression

理由：
- 透明；
- 概率可校准；
- 是很好的分类基准。

### 候选
- RBF-SVM
- Random Forest / ExtraTrees
- Gradient Boosting / XGBoost / LightGBM

## 每个标签必须单独检查

1. 正负样本比例
2. 缺失情况
3. 变量筛选稳定性
4. 最佳模型
5. 最佳阈值
6. 概率校准

公开的后续研究报告过这些标签存在不同程度类别不平衡，因此原始 `ADMET.xlsx` 必须重新计数，不能默认 Accuracy 足够。

## 评价指标

至少：
- balanced accuracy
- precision
- recall
- F1
- ROC-AUC
- MCC

当正类稀少时增加：
- PR-AUC

如果 Q4 使用预测概率：
- Brier score
- calibration curve

## 严格防数据泄漏

任何：
- SMOTE
- random oversampling
- 特征选择
- 标准化
- 阈值选择

都必须放在训练折内部。

不能：

> 先对1974条全数据过采样，再做交叉验证。

## 为什么不优先做一个多输出神经网络

可能存在标签关联，但：
- 样本不大；
- 五个标签不平衡程度不同；
- 评价语义不同；
- Q4需要可解释概率。

因此先建立五个强基线更稳；多任务网络只能作为改进实验。

# Q4：描述符范围与“至少三个 ADMET 较好”

这是四问中最容易被“智能优化算法”带偏的一问。

## 先解决标签语义

题面可直接确定：

- Caco-2：1 更好
- HOB：1 更好
- hERG：0 更好
- MN：0 更好

但 CYP3A4 只定义：
- 1 = 可以被 CYP3A4 代谢
- 0 = 不可以被 CYP3A4 代谢

题面没有直接说明哪一个必然“更好”。

因此必须：
1. 明确给出 Q4 中对 CYP3A4 的建模约定；
2. 给出药理学解释或题内近似；
3. 至少做一次“把 CYP3A4 favorable 设为1/设为0/不计入三项”敏感性分析。

禁止把五个标签简单求和。

## 推荐主路线：经验可行域 + 解释性规则

### 第一步：在真实样本支撑区域内定义“好样本”
根据：
- 高 pIC50（如训练集前20%或依据任务定义阈值）
- 至少三项 favorable ADMET

得到“优良化合物子集”。

### 第二步：识别稳定描述符
使用：
- Q1重要描述符
- Q2/Q3 permutation/SHAP/稳定性证据

找活性与ADMET共同相关的少量变量。

### 第三步：生成区间/规则
可用：
- shallow decision tree
- rule fit / subgroup discovery
- quantile ranges
- partial dependence / ALE

输出类似：

> 当 descriptor A 位于 [a,b]、B > c，并满足 C 的某个范围时，高活性且 ≥3 favorable ADMET 的概率明显上升。

### 第四步：bootstrap 稳定性
重复抽样检查区间是否剧烈变化。

## 为什么不推荐直接对729个描述符跑 PSO/GA

最大的风险不是求解器，而是：

> 优化出来的729维数字组合可能根本不对应任何真实可存在的分子。

分子描述符之间受到化学结构的复杂约束，不是729个独立旋钮。

因此如果采用连续优化，必须附加数据流形/可行域约束，例如：
- kNN 距离约束
- one-class model
- isolation score
- 与训练化合物的相似性约束

否则结果只能叫：
“模型空间中的数学最优点”，
不能叫：
“可实现候选药物”。

## 多目标优化什么时候值得用

当：
- 已经有可靠的连续 pIC50 surrogate；
- 五个ADMET概率已校准；
- 描述符可行域有定义；
- 希望展示 activity / ADMET trade-off；

可以再加入：
- NSGA-II/III
- constrained Bayesian optimization
- PSO/GA

但它们是**求解器**，不是 Q4 最核心的建模思想。

# 总体推荐路线

```text
Q1
稳定性特征选择
ElasticNet + 非线性重要度 + 冗余控制
↓
Q2
PLS/ElasticNet vs SVR vs Boosting
nested/repeated CV 选胜者
↓
Q3
五个标签独立比较
Logistic / SVM / RF / Boosting
不平衡处理放折内
↓
Q4
先定义 favorable 语义
↓
经验可行域 + 解释性区间
↓
必要时再做带可行域约束的多目标优化
```

## 这份基线最想训练的不是算法名

而是四个习惯：

1. 先定义数学任务，再选算法。
2. 先设计验证，再比较模型。
3. 先查标签语义和数据泄漏，再看 Accuracy。
4. 先定义可行域，再运行智能优化算法。
