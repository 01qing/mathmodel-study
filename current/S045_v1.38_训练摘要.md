## Q1：路径趣味性与游线优化

作者链：可通行域 → 骨架/关键节点图 → 长度、转折、交叉、重复、异景 → 五指标趣味性 → 路径总代价 → 改进遗传算法。

Core 结论：表示层可迁移，但优化证据不闭合。Eq.(5.67) 文字说包含长度且列出 λ1,λ2,λ3，公式却只有 `-λ2 S + λ3 R`；Eq.(5.71) 又用长度与重复定义 GA 适应度，和前一节 scenic-interest cost 漂移。任意节点序列单点交叉/随机节点替换不保证图邻接。打印代码实际 `dijkstra_adj()` 求最短路，并用 `force_connect_components()` 直接连接最近分量；没有 GA 定义原语。打印 exoticness 只统计邻域元素类别数并除以线段长后 `log1p`，也不是正文完整异景模型。

6小时主线：可行几何→简化图→透明异景/可视代理→k-shortest/RCSP/epsilon 候选→raw objectives→硬约束 replay。GA 只有在同预算稳定提升且算子可行时晋级。

## Q2：幻境感

作者链：多特征子区 → GMM-MRF/EM/ICM/BIC → 开阔/围合 → 开合节奏 → 寄畅园参考归一 → `Hg=100(0.45S+0.55R)` → 灵敏度。

表6.6十行综合分均可由 0.45/0.55 公式精确复算到一位小数。但寄畅园本身用于阈值、分母和100分锚定，因此不能再用“寄畅园第一”验证模型。打印代码没有 GMM/MRF/Potts/EM/ICM/BIC，而是坐标 KMeans/MiniBatchKMeans；`openness=np.random.random()`，并存在从图中假定的 score 数组。

最严重的新错误是 sensitivity axis mismatch：每个 α 只生成一个整体平均分，`scores` 的索引是参数场景，却被 `argsort(scores)` 当成园林排名，与真正以园林为轴的 `total_scores` 排名做 Kendall。长度碰巧都是10，不代表对象相同。

Eq.(6.76) `μ±1.96σ` 若 σ 为扰动分数标准差，应称分布/参考区间；要叫均值置信区间需 SE 或 bootstrap CI 等明确 estimand。

## Q3：相似度与外部鹤园

作者使用 Q1/Q2 综合向量、余弦和 Jaccard 融合并内部扫描 α≈0.7，再以鹤园做外部应用。Core 保留两个关键门禁：异数量纲特征进入 cosine 前必须有 reference/train-fitted scaling；Eq.(7.3) 是 threshold-set Jaccard，而 Eq.(7.11) 实际是连续 `sum(min)/sum(max)`，不能沿用同一语义标签。

鹤园没有独立相似度/美学真值，因此只能支持 applicability/face validity，而不是 accuracy/generalization proof。打印 p94 甚至直接写死鹤园十项相似度，并将 `-0.791→0.209`、`-0.857→0.143`，两者恰好都是 +1，但没有全局变换合同；相似度公式和 α 扫描也未见实现。

原 PDF p59 视觉确认 Eq.(7.13) 为 `1-|A自然/A总-A人工/A总|`。文本抽取丢失绝对值符号，故视觉公式审查优先。
