# 2022-C CONTAMINATION GUARD

Before Run A, Run B and blind evaluation are all frozen, prohibited:
- 2022-C excellent papers
- reference answers
- solution blogs/articles
- solution repositories/code
- targeted web searches for 2022-C solution/model routes
- passing A output to B or B output to A
- running A and B in the same chat/context

Permitted:
- official problem statement
- official four XLSX attachments
- sealed MathModel-Core v1.41.0
- generic software/documentation required to execute an independently chosen method, provided it is not 2022-C solution material

If contamination occurs, record source, time, exact information exposed, affected condition, and invalidate the run when required. Never silently continue a contaminated run as blind.
