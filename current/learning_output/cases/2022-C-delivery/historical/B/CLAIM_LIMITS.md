2. Run B is not compared with Run A here; no role-superiority conclusion is permitted.
3. The strongest benchmark-level conclusion remains unavailable until the blind paired evaluator compares anonymous A/B bundles.
4. The 9 s paint-body availability cadence is an explicit inference from the official `9C+72` theoretical-fastest formula, not a separately stated sentence in the problem.
5. The 9 s inter-parking move is represented by retaining the source parking-region code until arrival because the 74-code dictionary has no intermediate lane-motion code.
6. Policy selection used the same official instances and is therefore in-instance optimization, not generalization evidence.
7. Reviewer PASS is scoped to reproducibility/feasibility under the registered model contract and to matrix/score provenance; it does not certify optimality.
