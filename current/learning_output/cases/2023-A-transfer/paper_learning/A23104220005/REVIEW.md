**已核验范围：**我们的有限重传固定点计算得到 67.1744 Mbps，支持作者 67.17 的理论量级。冻结仿真为 65.24496 Mbps，不能因其没有贴合论文 66.87 就判错，也不能把两种仿真当作相同实现。附录使用累计浮点时刻的精确相等判断并发；本轮用独立 Python 调度探针比较精确相等与容差分组，结果见 LEARNING_CHECKS.json。探针采用统一固定时长和 Python 随机数，未复刻 MATLAB 的边界分母及所有逐项加法顺序，不能声称复现论文的均值，更不能将全部差异归因于一个错误。

**学到并采用：**写出“状态转移为什么对应冻结、重传和复位”，同时呈现理论与仿真有符号偏差。保留简单固定点作可解释基线；主要数值继续来自明确时间语义的离散事件模型。若需要收紧理论误差，应考虑联合退避状态，而非仅提高固定点求解精度。

## 问题三：隐藏节点首先要求统一碰撞时间口径

作者第 8、25 页以数据帧时长加 SIFS 定义脆弱时间，构造隐藏节点在该窗口内发送的概率，并将独立丢包率 Pe=0.1 合入失败概率。第 26 页公式 (40) 的 TIN_Hidden 是数据时长的一半，普通 Markdown 丢失的 1/2 已从 raw_layout 找回；公式 (32) 在两份文本中仍缺失，不能据此完整恢复求解器。

**作者主张：**基准理论 49.1793 Mbps，七组参数理论误差均低于 5%，且系统性高估。表 2 的理论值和误差已转录用于后续同题横向比较，未把误差反算出的数值冒充原始仿真数据。

**部分核验与区别：**冻结模型按数据帧正长度交叠判失败，使用理想 ACK 假设；作者用“数据＋SIFS”比较起点差。两者不是同一事件定义，因此不能直接以谁更接近 49.18 决定优劣。冻结解答的 Poisson 闭合也是粗近似，相对自身仿真明显高估，不能当作精确答案。正文第 29 页所谓仅改变重传次数的图 5.14(a) 与图 5.15(b) 比较，按图注却改变了速率；不能从这对参数推导重传影响。CW 的部分比较还同时改变重传上限，应说明混杂。

**学到并采用：**参数扫描应同时报告偏差方向和机制；统计窗口必须明确。我们补充同一条连续轨迹中的每秒逐节点吞吐量，原有同速率、同窗口的 r=6 与 r=32 对照继续保留。优先采用事件仿真；隐藏节点窗口解析作为解释候选；Poisson 近似仅作低成本基线。需要更强理论时应先补齐事件定义及缺失公式，而非无依据校准到作者表格。
