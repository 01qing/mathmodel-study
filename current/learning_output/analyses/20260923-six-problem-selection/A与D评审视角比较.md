# A与D评审视角比较

日期：2026-09-23。结论：仅考虑本助手及当前Core工作副本，**继续优先A，其次D**。这是针对能形成何种作品的条件判断，不是某题天然获奖率的统计结论。本人不是实际评委，以下按公开原则模拟评审关注点。

## 公开资料能确定什么

1. [2026官方参赛邀请函](https://cpipc.acge.org.cn/cw/contestNews/detail/4/2c9080189dcfa24e019dddacc24a1314?page=1)说明论文要做相似度检测，文献与他人程序须标来源；查重阈值由专家委员会确定，没有给出固定百分比。不能套用其他数学建模竞赛的查重阈值。
2. 同一邀请函给出全国一、二、三等奖队数原则上不超过参赛队总数的1.5%、13%、20%，并说明数模之星按各题集中评审成绩推荐。这些是整体规则，不是本地A/D练习题的获奖率，不能据此算A或D更容易。
3. [上海海事大学2024研赛通知](https://gs.shmtu.edu.cn/2024/0619/c8059a235593/page.htm)概括评奖重视假设合理、建模创造性、结果正确及表达清晰。它是公开研赛通知，不是2026每道题的具体打分表。
4. [高校公开答卷指导](https://shumo.hrbeu.edu.cn/_upload/article/files/6b/a5/5776d06c40109c3f0abc261deff6/ef49cb3e-8fad-4cd7-8da2-261ea37a0a36.pdf)同样重视建模、结果检验和清晰表达；作为一般写作参考，不冒称当届评委内部评分细则。

本次未获得可用于估计当前A/D获奖率的“选题队数—有效交卷数—分奖项获奖数”完整数据，也未验证本地标为练习题的文件与当届正式试题完全相同。不采用卖课博客所称“冷门题更易获奖”“华为命题必有优势”等说法作为依据。

## A与2025年相似是否构成劣势

题材和基础机制相近，这是事实。已有Train记录的2025-A研究核内拓扑顺序、内存分配/SPILL和时间优化；本题研究多核切图、分核、共享DDR、跨核同步及L2复用。新的决策对象和评估机制已发生实质变化。

相似带来两面影响：已有学习能帮助理解约束；也可能使方案被旧问题带偏。应明确把旧方法放在可引用的基线位置，重新推导和实现新增决策。没有找到公开规则规定“题材与去年接近就扣分”，但这不意味着复用旧论文文字、图表、程序无需引用，或仅改题名就有创新。

真正危险的做法是：主篇幅仍写旧题内存布局和FREE-first，忽略多核切分与带宽；沿用旧题搬运上限或旧模型数值；把既有评估器当作自己的算法贡献。此类作品不仅创新不足，也可能没有回答当前题目。

## 如果按评审原则审A

我会先查三个场景、规定核数、全部图是否覆盖，方案是否合法，结果是否确由配套程序得到。其次看性能改善来自哪里：是否同时考虑关键路径、跨Task通信、共享输入复用和缓存压力；方法在不同图结构上是否稳定；改进是否靠更长运行时间或逐图手调。最后查正文与代码是否一致、速度/搬运量是否同口径、有没有诚实报告变差图例。

A的强项是成果可比较、改进可量化。漂亮的数学名字不会替代图覆盖率、可行性、加速比和消融。建议的创新方向是“通信与缓存压力驱动的切图—分核协同”以及“场景变化下的规则选择”，它们目前只是候选方向，必须用实验确认收益。

## 如果按评审原则审D

我会先看是否逐箱完成、所有硬时限和能量限制满足；无人机、电池、中继和能源组件是否有重叠占用；通信是否覆盖爬升、巡航、下降和投送全过程。再看联合优化相比分别规划路线和中继是否真的改善，资源配置对安全余量和通信条件是否稳定。Q4是否在不改变Q3任务的前提下分区，也是关键。

D的优势是综合性强、路线与时序及资源图易展示，能够形成有实际解释的决策建议。但难点隐藏在可行性细节；用标准VRP加几个权重，给一张地图，不能自动成为完整协同优化。只查航点通信或者忽视充电周转，可能使最终调度不可执行。

## 为什么当前仍选A

这不是“评委偏爱A”的推断，而是对当前可交付质量的判断：

- A对应已评审的2025-A四篇及具体模块，迁移距离更短。D主要拼合不同案例的经验，缺少已验证的完整无人机系统。
- A的配套评估器已在一个样例的三个入口运行成功，且全部100图可直接读；D仍需新建覆盖物理、通信、时间和共享资源的独立验证器。
- A的原创增量可以直接体现在新问题的性能上，旧题相近无需成为核心障碍；D更大的建模自由度也意味着更多未经验证的假设。

**以较稳妥地产出有竞争力的完整作品为目标：A优先。以冲击最高奖为目标：仍把A作为当前首选，但没有足够证据断言A的一等奖概率高于D。** 若D获得严格可行且联合改进明显的方案，完全可能比只做到普通启发式的A更值得高分。

若A在全部图及核数上没有稳定优势，而D已把全过程通信与资源重放做实，我会改选D。现在没有这样的对照结果，不能为了题材看起来更新而直接反转排序。
