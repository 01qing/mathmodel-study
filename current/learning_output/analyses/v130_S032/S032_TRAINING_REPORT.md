## 2. 四问的任务本质

**Q1** 是钻孔展开图的前景稀疏语义分割：从岩石纹理、泥浆、钻进痕迹等结构化干扰中识别裂隙像素。独立验证单位应是原始图像/钻孔/深度块，而不是像素或同源 patch。

**Q2** 是“分段归并 + 物理约束周期曲线拟合”：从二值裂隙区域提取中心线，将可能属于同一裂隙的片段归并，并拟合振幅、周期、相位、中心线位置。周期由钻孔周长约 94.25 mm 提供强物理约束。

**Q3** 是“轮廓采样敏感性 + 粗糙度指标估计”：从复杂裂隙轮廓获得物理坐标，比较等弧长与曲率加权采样，计算 Z₂ 并代入题给 JRC 经验公式。

**Q4** 是“空间兼容性/连通网络推断 + 不确定性驱动的补充观测设计”：将多钻孔二维裂隙映射到三维空间，评估可能连通关系，并在不确定区域选择三个补充钻孔。

## 3. Candidate Model Competition 结论

### Q1

六小时 Baseline 应先做“按原图/钻孔分组切分 → 形态学或基本 U-Net → IoU/F1/Recall + 失败案例”。作者使用 CLAHE、双边滤波、Sobel、ResNet50、ASPP 与注意力门控，结构上合理，但只有在 grouped holdout 上稳定提升后才值得升级。大模型/大型视觉 Transformer 不应在样本独立性和数据量尚不明确时直接进入主线。

### Q2

六小时 Baseline 应采用“连通域 → 端点距离/方向兼容归并 → 骨架/中心线 → 固定周期的有界鲁棒 least-squares → R²/残差/物理范围 reject”。作者论文声称 DBSCAN、频域初值、LM、RANSAC、Huber 等鲁棒链，但打印代码主要可见质心 DBSCAN 与普通 `least_squares`，因此算法标签不能直接当作已实现事实。

### Q3

六小时 Baseline 是“统一像素到毫米标定 → 轮廓平滑 → 多采样密度等弧长 JRC → 曲率加权作为敏感性分析 → 报告未截断 Z₂/JRC 与饱和率”。作者的多尺度 LoG/注意力思想可作为候选，但打印附录没有展示该主链，且存在按图像硬编码的 `SCALE_FACTORS` 与 JRC 0–20 截断。

### Q4

六小时 Baseline 更适合使用“透明几何兼容性分数 + 参数/权重敏感性 + Monte Carlo/Bootstrap 传播上游误差 + expected information gain 或稳健 MCDA 推荐新孔”。如果没有概率标定证据，不应把 0–1 加权分数称为“概率”。作者的 AHP/投影寻踪遗传算法可作为高风险替代，但当前证据不足以说明 9.95 比 8.40 就代表真实钻孔方案更优。

## 4. 关键审计发现

### Q1：分割验证与指标来源

论文表 4 报告形态学、U-Net、改进 U-Net 的 Accuracy/IoU/Recall/F1，其中改进 U-Net 为 98.7% / 73.1% / 79.1% / 84.8%。但没有看到足够明确的训练/验证/测试独立切分合同。若使用同一原图的像素或 patch 跨集合，性能会被高估。

对于同一个 pooled confusion matrix，有 `F1 = 2 IoU / (1 + IoU)`。由表中 IoU 反算得到约 76.24%、79.08%、84.46%，与报告 F1 76.6%、80.4%、84.8% 存在不同程度差异。这**不能直接判为错误**，因为可能来自 per-image/macro 与 pooled/micro 聚合差异；正确动作是要求 aggregation provenance。

论文声称“改进损失函数/类别不平衡处理”和约 50% 训练效率提升，但打印训练函数将 `criterion` 作为外部参数传入，没有展示损失定义；也没有找到能支撑 50% 的受控计时对比。相关结论保留为作者主张，不升格为已核验事实。

### Q2：论文方法名与代码原语漂移

正文描述了更复杂的区域距离、鲁棒拟合链；附录中可见 `DBSCAN_EPS = 50`、`min_samples=1`，并基于区域质心做 DBSCAN。正弦拟合打印代码主要是固定周期的 SciPy `least_squares`，没有看到完整 RANSAC/Huber/IRLS 实现。

结果表还出现极端参数：图 2-8 裂隙 2 的振幅约 975.632 mm、R²=0.6207。该结果说明 Core 必须增加“物理参数范围 + 残差/拟合优度 + reject/unmodelled”的接受门禁，不能把“优化器成功返回参数”当作有效裂隙模型。

### Q3：JRC 结果链存在强 provenance 风险

打印代码在计算 Z₂ 后乘以按图像硬编码的 `SCALE_FACTORS`，再代入 JRC 公式，并执行 `np.clip(jrc, 0, 20)`。这意味着最终数值受到样本特定缩放和硬截断强烈影响。论文正文一处又描述“均值约 75”，与 0–20 的 JRC 范围/代码截断直接冲突。

因此新增两条通用门禁：样本特定校准常数必须有外部来源或 train-only 校准+held-out 验证；大量结果触及 clip 边界时，应报告饱和率并分析未截断量，不能直接用截断值做相关性结论。

### Q4：伪概率、熵计算与内生评分

Pgeo/Pjrc/Pconn 使用多个人工权重、距离尺度和阈值。数值被限制在 [0,1] 并不自动使其成为概率；没有标定时应称“连通兼容性分数”。

附录中一个不确定性函数先把 histogram counts 归一化后算 Shannon entropy，这是合理离散实现；另一个函数却使用 `np.histogram(..., density=True)` 后直接把密度高度当概率计算熵，数学上不成立。

AHP 部分文字描述两两比较和一致性检验，但正文实际直接给出 `[0.5,0.3,0.2]` 权重，未展示完整判断矩阵/特征向量/CR。投影寻踪 GA 的两个算术交叉公式完全相同，两个子代在交叉后相同；`Ddensity = mean(1/(1+Δz))` 在最大化时反而奖励较小相邻间距，与“提高区分度”的叙述存在方向张力。

最后，“投影寻踪平均综合得分 9.95 显著高于 AHP 8.40”属于**内生目标比较**：评分规则本身被重新优化，且未报告独立工程结果或统计检验，不能证明真实补充钻孔效果更好。

## 5. 本轮写入 Core 的通用规则

1. 图像任务必须按原始图像/对象/采集组先切分，再做 patch/tile；禁止把像素随机切分当独立验证。
2. IoU/F1 等存在代数关系时，先追踪 pooled/macro/per-image aggregation，再判断是否错误。
3. 非线性拟合必须有物理边界、残差/拟合优度和 reject/unmodelled 状态。
4. 样本/数据集特定的校准常数必须有来源或 train-only 校准与 held-out 验证。
5. 大量 clip 饱和时必须回看未截断量与饱和率。
6. histogram density 不等于离散概率质量，不能直接代入 Shannon entropy。
7. [0,1] 的加权分数未经校准不能称概率。
8. 多阶段“分割→拟合→网络→决策”必须传播上游不确定性。
9. 优化后的复合得分变高不是外部验证；推荐问题优先使用 held-out outcome、反事实/仿真恢复、expected information gain 或外部效用。
10. 算法名称继续还原到真实公式和代码 primitive；正文声称的方法未出现在实现中时保持 `not_verified/contradicted` 边界。
