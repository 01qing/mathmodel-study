# S015 四问候选模型竞争（Dev比较学习）

本文件写于独立解答冻结、合法打开S015之后。是模型决策审查，不是再次独立解题。作者事实见AUDIT_FINDINGS.md及原PDF；局部算术证据见AUDIT_REPLAY_RESULTS.json。所有复杂模型均未获得相对统一Baseline的独立稳定实质增益证据。下面的6小时流程是可执行预算设计，未冒充本轮完成的全国数据重跑。

## Q1：时间和空间特征描述

目标先固定为同一有效陆地支持域上的年累计降水mm、空间面积加权均值、五类覆盖份额和变化；不要将cell-day均值、全体格点总和、非零占用率混为一个指标。降水1990—2020，土地1990—2019，2020缺口必须显式保留。

- Baseline：沿用冻结方案的日累计→年累计→共同有效域面积加权，以及五类净变化；先给数量级、趋势与地图，保持数据源和统计对象一致。
- 作者方案：年/月mean、sum、sd，多地图和误差条，经典加性季节分解，动态度与非零格点成分度。
- 主要替代：稳健斜率和块bootstrap；季节分解用于解释，异常年份另用分位数/Rx1day等直接极端指标。
- 不推荐：根据SD变大就声称灾害频率升高；把mean±SD称为估计不确定性；在每年不同色标地图上直接比较颜色深浅；复制不闭合的成分度。
- 为什么选：最少处理即可回答题面，聚合能用微型数据和面积守恒核验。作者的多时尺度可视化值得保留，但需由同一个统计结果源生成图和正文。
- 为什么不选：新增统计名称没有修复sum/variance混用；季节分解解释季节性不自动提供未来预测精度。
- 何时切换：明显非线性趋势或异常值影响OLS时，引入稳健描述；只有单独预定的历史外推评估显示持续增益，才升级预测模型。

6小时：0—1h日历/缺失/共同支持审计；1—3h日年聚合、面积和份额；3—4h趋势与季节性；4—5h守恒、分母、恒定场/缺失场测试；5—6h统一色标地图、表格与限制。

可迁移模块：统计类型标签{sum,mean,SD,variance}、空间权重、日历与有效域、图表同源。错误模式：统计名称漂移、时间尺度漂移、五类非零支持不同、误差条被当置信区间。复现R2边界：打印降水汇总代码可审计，土地指标完整生成链缺失；未重跑作者全国结果。

## Q2：地形—气候相互作用

作者使用日降水及等级，原冻结解答用年度Rx1day，两者评价目标不同。若采用日暴雨事件任务，应定义y=1{日降水达到预定阈值}，全部特征须在预测时可获得，样本是格点日，保留有效暴露和原始患病率/事件率。

- Baseline：日事件任务先用训练期分区/季节频率，再用正则logistic含预定地形和季节项；年度Rx1day任务继续保留冻结气候态，不偷换目标重排榜。
- 作者方案：类别欠采样、相关图、联合均值方差Gaussian模型、决策树/条件推断树、MCP变量选择。
- 主要替代：两部模型（是否降雨+正降雨量）、GAM预定交互、类别权重浅树；若建连续尾部模型，另固定阈值和有效样本数。
- 不推荐：抽样后不校正就报告总体风险；从92个病例的中位数推出必要条件；将同日降水输入降水等级预测并称独立预测；把相关或SHAP方向直接写为可干预因果效应。
- 为什么选：分区频率揭示基率难度；简单模型能先检验时空外推是否成立。地形和气候交互只能在共同目标、特征可用性和留出机制固定后比较。
- 为什么不选：Gaussian残差诊断图p42明显右尾偏离和尺度变化，不能将“画了诊断图”视作假设通过；缺少完整拟合链，不能照搬MCP或联合模型参数。
- 何时切换：若校准、少数类召回/PR及分区稳定性均显示匹配预算下的实质增益，再升GAM或树模型；若高斯残差失配，比较分布/链接更适合的候选，而非只增加优化器复杂度。

6小时：0—1h目标/预测时点/标签依赖；1—2h按时间和空间块冻结划分；2—3h原总体频率与logistic；3—4h只在训练中抽样/加权并加入有限交互；4—5h留出校准、召回和错误空间分布；5—6h效应限制和失败条件。

可迁移模块：标签依赖图、病例/总体分母合同、训练内重采样、残差诊断后选分布。错误模式：病例阈值误读、非线性链接符号误读、目标标签回流、图矩阵标签错序。复现R2边界：预处理可静态读，关键模型拟合和同一数据版本未完整提供。

## Q3：未来脆弱区域与成灾条件

成灾标签不同于暴雨阈值标签；历史空间原型不同于未来演化。原冻结解答公开采用未校准的条件情景，不可拿作者历史标签AUC作为替代评价器。

- Baseline：有灾害真值时先比较历史分区事件率/持续性；无真值时明确输出条件危险性及敏感性范围，不输出经验证的灾害概率。原冻结方案维持条件阈值与持续性情景。
- 作者方案：历史经纬度与气候均值GMM九类→赋风险名；XGBoost+SHAP；SVM和RF预测由rain>6构造的标签，地图标2025—2035。
- 主要替代：外部灾害记录和预测时点可用驱动下的概率模型；有可靠未来情景驱动时开展条件预测并做历史回测；GMM仅作为描述原型或模型分区候选。
- 不推荐：把阈值重建当未来灾害预测；把样本拟合和OOB混排；把分类标签ROC当连续概率排序证据；仅看准确率而忽略41个正类的召回；直接称9类全局最优。
- 为什么选：先分离观测到的危险因子、暴露、脆弱性和假设参数，能审计“能回答什么”。缺灾害真值时收窄结论比精确伪标签分数更可靠。
- 为什么不选：图4-4/4-6的候选范围到9，边界最佳不能证明范围外更差；GMM没有时间状态；标签来源和预测可用性没有解除循环。软件默认行为核查已明确SVM拟合值和RF OOB的区别，不一概否定OOB。
- 何时切换：只有新增真实灾害标签、明确未来特征来源、同一时间空间留出和预算，并相对持续性取得稳定改进，才可升级为经过验证的未来灾害预测。

6小时：0—1h目标与标签谱系；1—2h整理情景输入、区分已知和假设；2—3h持续性及条件阈值；3—4h历史回测或机制约束检查；4—5h参数/排名敏感性；5—6h风险图与不确定性说明。无真值时不硬造AUC。

可迁移模块：forecast_origin/available_at、伪标签谱系、prediction_scope、阈值与排序性能分开、情景参数登记。错误模式：历史图挂未来年份、单实例解释泛化、OOB与拟合误判、类不平衡掩盖漏报。复现R2边界：缺new_data.xlsx及作者锁定环境，未复现未来地图。

## Q4：土地变化结构与用途

描述分区差异、预测未来土地变化、证明政策效用是三个不同目标。作者主要完成前者，不能用显著性弥补后两者。

- Baseline：共同支持域的五类面积份额/净变化与简单分区；若需预测，以持续性作为首个历史回测对照。原冻结PCA/KMeans结构稳定性结果仍只承担描述用途。
- 作者方案：人口/GDP阈值地图；南北、东西和阶梯分区；Welch/Mann–Whitney及Cohen's d。
- 主要替代：按年配对差值+时间块bootstrap；有充分数据时构建土地组成变化模型或转移模型，并用时间留出比较持续性；下游政策效用必须单独预定评价。
- 不推荐：P值小就称预测准确；对同年、重复格点当独立观测；区域字段重名和位置选列；以图颜色饱和推断人口增加量；把东/西方向写反。
- 为什么选：先确认区域划分、有效面积和时间单位，再给方向和效应量，可以直接回答结构问题，并阻止分组名字和数据轴漂移。
- 为什么不选：正文方向与表/图矛盾；p71降水中位数差11.907与非负数据同一均值合同不相容，需要追溯；附录缺检验原始样本链。未来演化和用途证据仍缺。
- 何时切换：提供同一统计单位的历年组成数据并通过时间回测后，才从描述升级预测；有外部决策损失或真实下游结果后才谈效用增益。

6小时：0—1h区域键/单位/样本层级；1—2h份额与配对变化；2—3h描述分区和持续性对照；3—4h块不确定性/时间回测；4—5h图表方向与数值范围检查；5—6h用途边界。

可迁移模块：唯一分组键、实体轴、效果方向与显著性分离、非负统计范围约束。错误模式：换轴不换字段、把统计显著当预测验证、地图展示阈值影响解释。复现R2边界：聚合片段可审计，完整检验/人口GDP链未复现。

## 本篇七门兼容性检查

1. 输入输出接口：统一用(grid_id,date/year,variable,value,unit,mask_id)，不能直接拼作者位置列和冻结Rx1day表。当前未经转换的数据拼接不通过。
2. 变量定义：mean/sum/SD、日等级/多年均值阈值、暴雨/成灾必须分开；原作者链存在冲突，不通过直接组合。
3. 数据分布：20800抽样总体和5990100原总体不同；需训练内采样和目标总体评价才可通过。
4. 数学假设：Gaussian残差明显偏离；地理聚类不能承担时间外推；未经替换/验证不通过。
5. 量纲：年累计mm、cell-day均值、等级编号和预测margin不能互换；缺转换合同不通过。
6. 训练/执行阶段：预测时点不得取得标签构造用的结果变量；SVM拟合值、RF OOB、XGB随机留出需分别登记。当前不能组成公平竞赛。
7. 评价指标：保持同target、entity_id和留出集合；作者AUC、冻结Rx1day MAE、条件情景排序不混用。只有局部算术核验通过。

组合决策：吸收统计合同、分母、标签和评价范围审计作为候选规则；暂不导入作者模型参数或未来风险结论。跨S013—S016的最终方法图、规则去重、历史回归和题组Mini Transfer仍待S016完成；本篇不冒称题组闭环。
