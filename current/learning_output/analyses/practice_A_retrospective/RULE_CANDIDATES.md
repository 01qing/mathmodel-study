# A题复盘候选规则（未晋升封存Core）

来源：D:/数模/数模练习/A题解题。A整题保持暂停。本轮不是新增论文Train，也未使用练习题答案。

## 候选与证据

1. **任务类型必须规范化并验证分发。** mechanistic_simulation被原路线脚本回退成泛化模型。生成文件存在和结构合法不代表模型贴题。候选修复：维护显式别名；未知类型返回UNRESOLVED；任务要求、主方程与选定模型逐项匹配。独立测试是最小路由反例，不是原生产脚本修复的回归；后续需要对工作版真实脚本做集成测试。
2. **输入角色跨阶段一致。** 原loader正确跳过result模板，但计划生成器再次扫描时仍把它们加入数据计划。候选修复：每阶段必须继承manifest的role，禁止由扩展名/文件名重判；同时保留名字含result的合法原始观测。独立正反例已验证角色筛选机制，生产工作流尚未修复。
3. **单位相同还要核对测量对象和分母。** kg水/kg干空气与kg水/kg干药材不能仅因单位字符串相同而直接相减。A基线的等效边界是假设，不是物理识别结果。此规则与已有七门“变量定义/量纲”高度重叠，应补案例而不是再堆一条重复规则。
4. **表面或界面急剧变化必须局部收敛。** A均匀网格首次含水率误差0.0123569，表面加密后0.0002325（80vs160段）。独立指数边界层插值反例误差从0.351879降至0.029926；这是插值机制测试，不能当A非线性PDE独立复现。
5. **非均匀网格要同步修改离散算子。** 用实际相邻距离和控制体，不只换坐标。独立线性场导数可严格识别旧常步长错误；新平板扩散解析解误差随20/40/80段递减至3.87e-5。该平板使用均匀网格，不冒充非均匀圆柱求解器复现。
6. **输出位数、数值误差、物理准确性分开。** 四位小数仅是格式；未满足半末位误差预算不能宣称四位准确；收敛和守恒不证明边界物理模型成立。候选属于现有证据范围规则的具体扩展。
7. **运行账本包含实际读取的中间数据。** A的局部账本只列XLSX而求解器实际读取CSV，CSV转换来源未完整入账。这是新增自审发现：输入链应覆盖源文件→转换脚本/运行→CSV→求解器，不能用源文件hash替代真正输入hash。待集成回归，不把它记作已通过测试。
