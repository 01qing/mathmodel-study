# S013 与冻结独立解答：阶段性方法差距分析

状态：IN_PROGRESS。不是 S013 完整结案，也不是最终 S013–S016 Method Map。所有改进均为 Dev 暴露后的候选，不得回填冻结解答作为独立成果。

## Q1：统计量必须能解释空间支持域与时间单位

六小时 Baseline：在共同有效域按面积权重计算降水年累计与土地面积比例，配合趋势和空间差异图。冻结解答已采用该方向，但边界单元近似使面积不能视为精确行政面积。

作者方案：均值、极值、等值线和分类土地地图；GIS 裁剪有助于明确研究域。其日均×100数值痕迹与年累计描述不一致，原工作簿和裁剪边界也未恢复。

替代：按分区汇总并报告分位数，减少全国均值对地域差异的掩盖。不推荐以点插值后的平滑图反过来作为未经守恒核验的总量统计源。

当前选择：保留原始网格/明确面积权重统计为主线，地图作为表达模块。只有边界来源、重采样守恒和单位链验证后，才切换到更精细裁剪；不能因为图更平滑而升级。

## Q2：预测比较之外还要检验交互规律

六小时 Baseline：气候态预测配合地形、气温分层的极端日降水描述。冻结解答中复杂候选未赢得时间留出验证，保留气候态合理；但预测胜负不能独自回答地形—气候如何交互。

作者方案：浅决策树、土地类型分组和可读分支，具有沟通优势（原 PDF 30–36页）。然而土地类型不能替代地形，坐标不能证明地形因果，年度阈值也不能证明日尺度暴雨。第79页作者承认年度尺度难以捕捉短时事件。

替代：对一致的 Rx1/Rx5 目标，在相同时间/空间留出下比较加性模型、交互模型与浅树；用分块重采样评估交互方向和阈值稳定性。

不推荐：把高拟合分数、单棵树阈值或相关系数改写成因果机理。

当前选择：预测主线不变；解释模块另设稳定性检验。只有外部留出误差有稳定实质改善，且解释在不同块上稳定，才推荐升级。该新检验尚未执行，不能写成 PASS。

## Q3：区分危险度、暴露、易损性与真实灾害

六小时 Baseline：明确假设的相对风险/情景排序，报告缺失的灾害观测。冻结解答采用多情景，但尚无真实灾损标签，不能校准成灾概率。

作者方案：分维度指数、树阈值、ARIMA 输入预测、SVR 输出和空间叠加。分层概念有参考价值；实际打印链与所述指标存在差异，伪标签精度不构成灾害验证。

第43页新增语义核验：表5.1将坡度单位写成米，将降水滚动标准差称为地质稳定性，正文又称该量从 DEM 提取。这些定义不一致；不能用可计算性替代概念效度。

替代：分开报告危险度、人口/资产暴露与假设易损性；有观测标签后再做时空留出校准。人口/GDP 数据年份边界仍需明确，不外推成真实未来观测。

不推荐：直接复制作者灾害阈值，或把未来输入点预测经 SVR 映射后当作空间灾害概率。

当前选择：保留情景结论及限制。切换条件是取得独立灾害标签、区域化未来输入与回测优于持续性 Baseline；目前未满足。

## Q4：压缩精度与地理用途分别验证

六小时 Baseline：少量土地结构分区，报告重建误差、空间分布与时间稳定性。冻结 K=5 结果具备这部分证据，但没有充分验证实际用途。

作者方案：重心/方向/离散程度摘要，再与人口、GDP、降水叠加，提出简明地理界线（74–79页）。长处是把结构摘要连到用途；局限是视觉叠加没有独立效用比较，椭圆覆盖和资源面积不可混同。

替代：面积×覆盖率加权重心及协方差摘要；同时对 K 分区设未参与分区训练的下游评价。与单区、经纬度简单分区等同预算候选比较，并检验空间留出稳定性。

不推荐：直接采用“和仲线”，或以同一批用于选线的数据再次证明该线有效。人口/GDP曾用于选线就不能同时充当独立验证目标。

当前选择：K 分区主结果保持冻结；增补用途检验作为 Dev 新实验。只有独立下游任务有实质收益才接受组合。重心/椭圆仅为摘要候选，不凭视觉吻合升级。

## Method Composer 七门预检查

目标组合：冻结土地分区 + 可解释空间摘要 + 独立下游效用评价。

1. 输入输出接口：必须以唯一 cell_id/year 对接，禁止坐标取整后多对多合并；候选接口待实现。
2. 变量定义：覆盖率、实际覆盖面积、分区标签、椭圆面积分开登记；禁止相互替代。
3. 数据分布：统一有效域、年份和空间留出；作者裁剪范围未恢复，直接接入作者输出不通过。
4. 数学假设：协方差摘要不保证正态；不用一维68%覆盖规则解释二维椭圆。
5. 量纲：距离/面积使用合适投影，权重为单元面积×覆盖率；不能直接把经纬度方差称为平方公里。
6. 训练/执行阶段：分区、选线、权重和标准化只能使用训练部分；Dev后实验单独标记，冻结答案保持原样。
7. 评价指标：重建误差、描述覆盖和下游效用分别计算；不同目标的 R² 不可横向排名。

结论：尚未实现完整组合，状态 PENDING_IMPLEMENTATION_AND_VALIDATION；不是七门全部 PASS。
