# S032 / 2025-C MathModel-Core 训练摘要（v1.30）

S032 已按新版 MathModel-Core 协议完成 Train 学习：全文、71/71 原 PDF 视觉审查、打印 Python 附录静态审计、Candidate Model Competition、6 小时 Baseline、Result Registry、可迁移模块、错误模式、临时 2025-C Method Map、专项与历史回归。复现等级保持 R2。

最重要的训练收益不是“学到一个改进 U-Net”，而是形成四类更通用的决策能力：

1. 图像分割必须按原始图像/钻孔/采集组切分，不能让 patch 或像素泄漏制造高指标；复杂 backbone/attention 只有在独立组验证稳定超过 U-Net baseline 后升级。
2. 几何拟合必须把算法名还原到真实 primitive，固定已知物理周期、设参数边界、标准化振幅/相位，并允许 reject；优化器收敛不等于拟合物理合理。
3. JRC 等经验指标必须审查单位、采样密度、校准常数和 clipping；大量触顶时不能继续用截断值证明相关性。
4. 多阶段“分割→拟合→空间网络→补孔决策”必须传播上游不确定性。下游若直接用人工 JSON 真值掩码，只能算 oracle upper bound；手工加权的 [0,1] 连通分数也不能未经校准就称“概率”。

S032 本身发现的关键证据冲突包括：Q2 正文的 RANSAC/Huber 链未在打印代码中实现，R 的定义在全幅与半幅之间漂移，出现 R=975.632mm 的异常拟合；Q3 代码存在逐图 SCALE_FACTORS、0-20 clipping、正文 JRC≈75 冲突，并且所谓曲率加权采样的权重方向与“高曲率加密”目标相反；Q4 Pjrc 几何平均的文字与公式冲突，entropy 有一版把 histogram density 当概率，GA 两个交叉子代公式完全相同，邻接钻孔列表与 2×3 布局/正文分析不一致，9.95 对 8.40 只是内生综合评分而不是独立决策质量证明。
