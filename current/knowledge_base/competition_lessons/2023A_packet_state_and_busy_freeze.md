# 包状态、忙段冻结与可复用仿真

来源：2023-A第六篇A23102890028，p24–33、62–72、75–85；完整评审位于learning_output/cases/2023-A-transfer/paper_learning/A23102890028/REVIEW.md。

可迁移的组织方法：先建立理想情形，再加入噪声；公共时长函数统一参数；每一层分别检查机制和收益。加入噪声后还须追踪其对重传分布的反馈，不能仅乘一个成功系数。

1. 每个节点的当前包拥有自己的失败次数、退避阶段和计数器。成功或丢弃才结束此包，并显式初始化下一包；其他节点成功不能代替它清零。
2. 监听到忙段时冻结所有正在退避的相关节点，不以其原定到期时刻是否落在忙段内作筛选。交叠忙段按时间并集处理，完整时隙规则与DIFS另行明确。
3. 冲突使用参数化发送区间；时长、速率、载荷只保留一套来源。基础参数的硬编码通过不代表跨参数成立。
4. 吞吐分子只累计观测口径内已完成的有效载荷，分母采用实际观测时间。未来发送计划的最大值不能自动充当仿真结束时间。
5. 独立重复报告种子、观测长度及区间定义；极差不称置信区间。先锁定标定参数，再在未用于标定且参数身份明确的数据上检验。

本地只验证了隔离分支：3个重传序列、12个冻结样例（4个差异）、3个收益系数样例、3个时长样例。它们定位机制风险，不估计修复后全网吞吐，也不构成作者程序完整复现。适用范围为监听/干扰关系显式的事件仿真，其他系统须重新确定状态生命周期。
