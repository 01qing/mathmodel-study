# 2023-A：概率、求根与论文证据链

来源：2023-A-transfer十篇同题暴露后学习，重点为A23103360079、A23103840031、A23104860166、A23105330383。正式Core v1.41.0不变；本卡是本地经验，不能作为盲测证据或自动扩充冻结Train。

检索触发：并发系统、有限状态更新、模型求根、仿真校验、误差比较。非WLAN题迁移结构，不照搬速率、时隙或概率闭合。

1. 为每个互斥事件分别保存概率、占用时间、交付包数。概率位于[0,1]且完备和为1；包数期望可超过1，不可代入1−Ps当失败概率。吞吐是期望收益/期望时间。
2. 清分母后的根必须回代有限和原式，并检查概率范围。p=0.5、1可能是多项式增根；小步长、迭代停止、算法名都不是方程求解成功证据。
3. 噪声与碰撞按条件关系合并，且失败反馈到退避状态。正长度交叠设置本次尝试的持久失败标记，端点相接不重叠；相邻忙区间取并集，等待完整DIFS与时隙。
4. 参数从同一配置对象传入正文计算、子函数、仿真与图表；记录单位及随机种子。零退避合法；Wi表示支持集大小，抽样0至Wi−1；成功/最终丢弃重置当前包。
5. 报告理论误差的分母、单位和独立样本单位。百分点不等于相对误差，极差不等于置信区间，累计窗口不等于独立重复，校准点不等于验证点。
6. 每问建立假设→事件→公式→代码→数据→图表的可追溯链。总量之外报告节点/群体分布；只证明总量接近，不足以证明机制正确。
