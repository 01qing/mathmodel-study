# 证据角色驱动的论文图表设计

本规则来自已审查优秀论文案例，目标不是复制某篇论文配色，而是学习**图表在论证链中的位置**。

## 1. 先定义证据缺口，再决定画什么

每张计划图至少记录：

- `purpose`：它要回答哪一个具体问题；
- `evidence_role`：data_sanity / mechanism / feature_selection / model_comparison / stability / transfer / uncertainty / interpretability；
- `cannot_prove`：即使图很好看，它仍不能证明什么；
- `comparison_unit`：文件、工况、时间段、样本或窗口。

不要固定“每问画 N 张”。没有新的证据作用就不加图。

## 2. 从 2025 E 学到的五类高价值构图

### A. 同一信号的机理四联图
适用：故障诊断、时序信号、去噪/重构。
建议：原始与重构、时域包络/细节、频谱、包络谱使用同一对象并列；坐标单位一致。
不能证明：单个代表样本不能证明全数据性能。

### B. 特征筛选证据链
顺序可为：相关热力图 → PCA解释方差 → 模型重要性/互信息 → 最终保留特征。
不能证明：筛选图不能替代独立测试；筛选必须在训练折内完成。

### C. 模型竞争
同一实验协议下并排混淆矩阵，共享 class order 和数值尺度；单独给汇总指标表。需要稳定性时，再用多随机种子箱线图。
不能证明：训练 loss 小或单次 accuracy 高不代表跨文件/跨工况泛化。

### D. 迁移前后
使用成对的 before/after embedding，并共享坐标语义；同时报告 MMD/CORAL 等定量域差异。目标域无真值时可画概率热图/置信度，但标题必须明确“预测概率/置信度”。
不能证明：t-SNE 视觉混合、MMD 下降、置信度高都不等于目标域准确率。

### E. 可解释性
优先形成：机理事前解释 → 对齐过程证据 → SHAP/attention/gate 的事后解释。全局图与单样本图分开。
不能证明：SHAP/attention 重要性不是因果关系。

## 3. 版式规则

- 同组比较图尽量共享轴范围、类别顺序和图例。
- 白底、少装饰、字号优先保证正文缩放后仍可读。
- 多面板只在对象/指标可直接比较时使用；否则分图。
- 不照抄优秀论文的固定颜色；颜色用于类别/域语义的一致编码。
- 结果图之后的正文必须写“观察→量化→结论边界”，不能只写“如图可见效果良好”。
