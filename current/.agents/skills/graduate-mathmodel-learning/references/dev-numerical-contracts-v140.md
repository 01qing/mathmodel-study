# v1.40 数值与评价合同增量

来源：S014 Dev审计及确定性局部反例，先于本轮阅读的独立解答保持冻结。与dev-data-contracts-v139.md及既有实体/量纲/模型竞争门禁联合使用；不引入作者特定阈值、权重或地名。

1. 多级平均保留有效样本数；不同组大小时mean-of-means不等于总体mean。年累计、有效日均、面积加权平均分别登记算子与单位；不要静默舍弃有效零值。
2. 展平的统计量、布尔mask和输出数组须共享shape及实体顺序；地理对齐另外核验CRS、transform、范围、分辨率、NoData。相同数组大小不证明相同位置。循环角先处理周期再插值，并处理向量均值为零时的未定义方向。
3. AHP等矩阵方法分别保存原判断矩阵、归一化矩阵、权重及生成原语；主特征向量、几何均值、列归一化均值不得混称。lambda、CI、RI(n)、CR逐项重放；数值近似不说明来自相同算法。局部与全局权重用indicator_id连接。
4. 效果大小、方向与显著性分别存储；分类区间明确端点并检验互斥/覆盖。趋势检验保留ties及时间依赖假设；趋势显著不自动支持外推更准。
5. 比较模型前固定target、heldout entity_id集合、单位、划分及预算。不同总体的R2不直接排模型；真实Y分层可作事后诊断，不能作为未知Y时的部署路由。事件率同时报告有效暴露分母。
6. 组合模型保存operator_id，乘积与加权和不得静默替换。组成数据声明是否完整类别；五类不完整时保留other或明确总量≤1，不能强行归一化后隐瞒剩余类。预测份额检查界限及总量。

这些规则只得到局部合同与错误检出证据。作者全链仍R2，独立Core能力提升NOT_ESTABLISHED；不因审计修复推荐复杂模型。
