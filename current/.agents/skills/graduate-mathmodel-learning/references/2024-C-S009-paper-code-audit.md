# 2024-C S009 论文—代码—结果一致性审计

## 证据边界

S009 已完成 71/71 页全文文字层精读与打印附录静态审计。作者原始工程和官方附件未在当前运行环境中挂载，因此 Q1–Q4 不宣称完成作者 pipeline 复现。Q5 打印代码片段是自包含的，已按原参数执行独立烟测。

## Q1 励磁波形分类

论文思路本身合理：把 1024 点波形压缩成形状、斜率和频域特征，再用 RF/MLP 分类。问题在于可见实现没有形成统一的数据契约：特征提取脚本只读取“材料1”；前文提取的是上升/下降速率、FFT、峰度、偏度，而分类代码中的 `X` 未定义，推理阶段又只选择“平均值、峰值、标准差”。论文还声称 MLP-RF 加权概率集成，但打印附录只有两个独立分类器。

因此新题不能只复制“RF+MLP”名称，必须先冻结 feature schema：每一列名称、顺序、单位、变换和来源必须在 extraction/train/inference 三处一致，并自动测试。

## Q2 温度修正 Steinmetz

优点是保留了 Steinmetz 机理结构，并比较 Solow、温度饱和、二次温度修正。主要证据缺口是四个模型均在拟合数据本身上比较 R²/MAPE，没有留一温度或分组外推验证，所以只能支持 calibration fit，不能证明跨温度泛化。

此外，公式、表格与打印代码中存在温度符号和参数录入漂移。多项式模型被描述为“初值敏感”，但表中两组初值对应的多数参数几乎相同；同时部分科学计数法在不同表中丢失数量级。以后所有机理参数必须写入唯一 registry，由正文公式、表格和优化代码共同读取。

## Q3 因素与交互

S009 使用 statsmodels 的分类主效应和两两交互项，形式上比单纯均值比较更接近题目。但响应是原始磁芯损耗，模型没有控制频率和 Bm。只要不同温度/材料/波形组的频率或磁通密度分布不完全平衡，ANOVA 的主效应和交互就可能混入工况差异。

更稳健的路线是：

`log P ~ log f + log Bm + T + W + M + T:W + T:M + W:M`

并使用稳健标准误、效应量和调整均值/置信区间。p 值不能直接当作“影响程度”。

表19 还存在明显交叉拷贝迹象：标题是“励磁波形-磁芯材料”，交互行却写“温度：材料”，数值又与另一张交互表重复。这类表格必须由模型结果对象自动生成，而不是手工录入。

## Q4 跨工况损耗预测

S009 的等效正弦频率 + 分材料/波形参数模型是有工程解释性的强基线。但 12 段参数表之间出现多处系数漂移，例如材料2正弦波 α 在不同表中为约 1.7181 和 1.781；梯形波也有十倍系数/小数差异。打印代码只展示一个文件/一个波形的拟合，并未展示完整 12 路 routing。

所以新的 Skill 规则是：物理分段模型可以保留，但必须具备统一 parameter registry、完整 routing、out-of-condition 验证和每个分段的支持域声明。

## Q5 双目标优化

论文写的是五个变量、混合整数、PSO 和双目标折中；打印代码却是 `scipy.optimize.minimize`，只含 `f, Bm, U` 三个连续变量，材料和波形没有进入决策向量。

打印代码约束：

- `f ∈ [50000, 320000]`
- `Bm ∈ [0.1, 0.3]`
- `U ∈ [25, 90]`

但论文给出的 694891.32 Hz 和 813076.12 Hz 都超过代码上界，22°C 也低于代码下界。论文正文说 PSO 温度 90°C，表33 又写 70°C。

对打印片段进行真实运行，`scipy.optimize.minimize` 收敛到约：

`f=50000, Bm=0.1, U=90`

而不是论文报告点。该烟测仅说明“打印片段的行为”，不证明作者完整工程一定相同；但足以证明当前可见代码不能支持论文所声称的混合整数 PSO 结论。

新的安全路线应先生成 Pareto front：显式最小化损耗、最大化 `f*Bm`，枚举/编码材料和波形，并限制搜索在训练数据支持域。最终推荐点再通过 ε-constraint、理想点距离或明确偏好规则选择。
