# 2024-A S004：论文—打印代码一致性审计

## 定位

S004（A24107120016，西北农林科技大学）是 2024-A 训练组第四篇。当前可用证据是 59/59 页全文提取文本和论文中打印的 MATLAB 片段；原 PDF 像素与可能存在的完整提交代码/原始附件数据没有挂载。因此本记录只对**当前可见论文与打印代码**负责，不把静态片段审计称作实际复现。

## 最值得迁移的结构

1. Q1 用实时代理替代全局雨流，并主动报告运行时间；正确升级方向是再补精确雨流金标准、边界循环和尺度误差。
2. Q2 先做物理基线，再通过残差曲线识别尺度和时滞问题；正确升级方向是将校准参数放到训练时段/风机，留出独立验证。
3. Q3 将总调度量改写为每台风机权重，等式约束转为归一化，适合大规模资源分配；必须在归一化后重新验证分量上下界。
4. Q4 的“去噪→延迟恢复→再优化→五方案消融”是较完整的论证链，应保留这种证据顺序。

## 打印代码中的关键风险

### Q1：重叠窗口不是独立循环

打印代码每秒取一个高度重叠的固定窗口，用 `max-min` 得到幅值，并把该窗口的 `1/N` 直接作为新损伤加到累计值。相邻窗口重复使用绝大多数载荷点，因此必须检查是否重复计数同一物理循环。趋势相似不能替代绝对尺度和边界循环验证。

### Q2：物理语义与校准

- `R=64.5` 的注释又写“假设50m”；`A=13685 m²` 也不等于 `π×64.5²≈13070 m²`。
- 论文把功率因子当成机械—电能转换效率使用，工程语义不成立。功率因子是有功/视在功率比，若需要转换效率应单独建模。
- `Ft` 中再乘3个叶片需要核对推力系数究竟是单叶片还是整个转子系数；标准转子推力式通常已经针对整个扫掠面积。
- 固定偏移978700和1秒时移属于数据驱动校准，必须独立留出验证。

### Q3：真正目标函数没有打印出来

附录“目标函数”标题之后再次出现 `GeneticAlgorithm` 主体，真正的 `evaluation`/目标函数实现没有给出；`Initialization`、`OperatorGA`、`enviornmentalSelection` 也缺失。因此只能确认论文叙述和顶层调用框架，不能宣称代码复现。

### Q4：跨风机 Kalman 状态泄漏

`x_est` 和 `P` 在 `for turbine` 外初始化。后一台风机从前一台风机最后状态继续滤波，建立了不存在的跨风机依赖。独立风机必须在每个实体循环内重置状态/协方差，除非模型显式定义了共享状态。

附录没有 LSTM、ARIMA、延迟检测和完整五方案调用链，因此这些部分仍属于正文方法证据，不属于代码实现证据。

## 论文结论的内部一致性

- 表7-3：方式2=延迟处理，方式3=去噪；后文结论又写“去噪（方式2）、延迟预测（方式3）”，标签交换。
- 表7-4：方式5 ACD 从方式1的 `5.4492e12` 降到 `5.2748e12`（约3.2%），但 APV 从 `1.5899e13` 增至 `1.7130e14`，约10.8倍。它体现的是疲劳与功率方差的明显权衡，不能表述成所有指标全面优于其他方式。
- 延迟检测按正文针对风速变化，却使用绝对阈值 `1e4`；对 m/s 量纲明显不合理，也不应与功率共用同一个绝对阈值。

## 新题使用规则

当新题出现“多个独立设备 + 滤波状态 + 实时优化 + 多指标结果”时，自动触发：

1. 每个设备是否重置隐状态；
2. 阈值是否按变量量纲分别定义；
3. 校准参数和最终评价是否使用独立数据；
4. GA/PSO/优化器是否真的打印/调用了目标函数；
5. 归一化、投影后是否重新检查逐实体约束；
6. 所谓“全面优于”是否真的在所有方向一致的指标上成立；
7. 实时性报告的是均值、整批吞吐量还是 p95/p99/max 单步延迟。
