## Q1 励磁波形分类

### 数学结构
一个样本不是 1024 个互不相关的普通变量，而是一条 1024 点波形。

### 基线
归一化波形 + 物理可解释规则/模板：
- 分段斜率
- 平顶比例
- 转折点
- 低阶谐波比
- 模板相关性

### 主模型
**波形工程特征 + Random Forest / SVM**

推荐顺序：

1. 先构造不可变 `raw_waveform`
2. 所有统计特征均从这个原始矩阵独立计算
3. 时间域 + 斜率 + 频域特征
4. 再比较 RF 与 SVM

### 为什么不先上 1D CNN
三类波形几何差异明显，样本规模有限，深度模型会增加调参与解释成本。只有在 engineered features 在跨工况验证中确实不足时才升级。

### 验证
随机分层只是第一层，还应检查：
- 按材料
- 按温度
- 按频率区间
- 幅值归一化
- 小幅相位平移

## Q2 Steinmetz 温度修正

### 基线

\[
P=k f^\alpha B_m^\beta
\]

### 推荐主模型

先在对数域：

\[
\log P
=
c_0+\alpha\log f+\beta\log B_m
+\gamma_1\Delta T+\gamma_2(\Delta T)^2
\]

等价于：

\[
P
=
k f^\alpha B_m^\beta
\exp\left(\gamma_1\Delta T+\gamma_2(\Delta T)^2\right)
\]

### 为什么这样选
它仍然是 Steinmetz 的乘法结构，只增加可解释温度修正，不需要一开始就让 \(\alpha,\beta\) 都随温度变化。

### 候选替代
- 只让 \(k=k(T)\)：最简单
- 让 \(\alpha(T),\beta(T)\)：只有 T×log f / T×log Bm 交互稳定时
- GAM：诊断非参数温度曲线

### 决策标准
不是训练 SSE，而是：

**leave-one-temperature-out 的误差。**

## Q3 三因素及两两交互

直接比较原始均值不够，因为频率和 \(B_m\) 是强混杂变量。

推荐：

\[
\log P
\sim
\log f+\log B_m
+T+W+M
+T{:}W+T{:}M+W{:}M
\]

其中：
- \(T\)：温度
- \(W\)：波形
- \(M\)：材料

使用：
- HC3 稳健标准误
- 效应量
- 调整均值
- 两两交互图

随机森林/置换重要性只做非线性稳健性验证，不替代显式交互模型。

## Q4 磁芯损耗预测

### 四类候选必须同台

1. 修正 Steinmetz：物理基线
2. Ridge/ElasticNet：简单统计基线
3. RF/ExtraTrees：树模型基线
4. HistGradientBoosting / XGBoost：主候选

特征包括：
- 温度、频率
- 材料、波形
- \(B_m\)、峰峰值、RMS
- 斜率特征
- 低阶谐波特征

目标优先测试：

\[
y=\log P
\]

### 推荐主路线
**梯度提升树 + 物理基线保留**

如果发现：

`physics prediction + residual ML`

在跨工况验证更稳，则升级为物理-数据残差混合模型。

### 验证必须两层
A. 温度×材料×波形分层 CV  
B. 留温度/留材料等跨工况诊断

随机 CV 最好，不代表跨工况最好。

## Q5 双目标优化

两个目标必须同时存在：

\[
\min \hat P(x)
\]

\[
\max fB_m
\]

### 最简单基线
由于主要连续变量其实只有 \(f,B_m\)：

**枚举材料/波形/温度 + LHS/密集采样 + Pareto 非支配筛选**

这比“为了优化而上复杂算法”更容易审计。

### 主模型
NSGA-II：

\[
F(x)=[\hat P(x),-fB_m]
\]

### 另一种很好的方案
ε-constraint：

\[
\min \hat P
\quad
\text{s.t. }
fB_m\ge E_0
\]

扫一系列 \(E_0\) 得到 Pareto 关系。

### 不推荐默认加权和
`0.5*loss - 0.5*energy`

没有偏好来源就没有理由。

### 可行域
不能只做全局 min-max box，还要控制：
- 材料×波形局部数据范围
- 最近邻/支持密度
- 分类组合是否真实出现
- 最优点是否总贴边
