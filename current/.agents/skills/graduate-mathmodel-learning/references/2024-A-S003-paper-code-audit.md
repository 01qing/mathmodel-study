# 2024 A S003：论文—代码一致性学习

## 适用场景

当优秀论文给出复杂算法名称、流程图和部分附录代码时，不把“论文写了”直接等价为“代码实现了”。逐项建立正文组件→公式→函数/调用路径映射。

## S003 四问训练结论

### Q1 在线疲劳

正文：自适应动态三阶段滑动窗口、AB初始窗口选择、阈值分段、尾部逆向处理、改进雨流。

打印代码：固定滑窗+重叠窗口损伤差分。默认函数写14，但批处理又传10；未见AB、动态阈值、分段和逆向尾部路径。`np.diff(window_damage)` 不能自动解释为物理非负疲劳增量。

规则：在线疲劳必须用边界转折序列测试“窗口内循环、跨窗口循环、尾端半循环”，并与精确批雨流逐时比较。

### Q2 物理约束回归

摘要称网格搜索，正文称随机搜索；代码35参数，正文最终列20参数；物理公式与标准化尺度未隔离。

规则：物理变量保留原始单位分支；缩放只用于统计/残差模型。若叶片半径为62.5 m，则扫风面积不能写成80 m²。

### Q3 Pareto + MPC

正文声称区域Pareto权重、LSTM风速预测、滚动时域MPC。打印代码固定0.5/0.5权重、无区域、无预测、无时域决策，属于逐秒静态约束优化的近似骨架。

特别检查 SciPy `type="ineq"`：要求 `g(x)>=0`。要表达 `|x-c|<=tol`，必须写成 `tol-|x-c|>=0`。

规则：只有同时存在状态/预测模型、有限时域、跨时刻约束、只执行第一步并滚动更新，才将实现标记为 MPC。

### Q4 鲁棒优化

正文：Kalman、延迟补偿、鲁棒MPC、PSO。打印关键代码没有Kalman、PSO或明确延迟补偿；`robust_objective` 未进入控制路径，且出现功率减风速的异量纲平方损失。

规则：鲁棒性论证按“扰动/延迟估计误差→预处理效果→下游目标与约束→严重度扫描”四层验证。

## 图表学习

S003文本中有42个图题出现，但核心Pareto方法没有编号的真实Pareto前沿图。以后多目标优化至少输出：实际Pareto点、非支配前沿、最终选中点、选点规则和敏感性。鲁棒方法至少输出噪声/延迟severity sweep，不以单个受扰数据集代替鲁棒性证据。

## 使用边界

当前只有全文提取文本和打印附录；原PDF像素、单独提交的完整附件代码与原始数据未取得。因此本记录可证明“打印代码与正文存在这些可见差异”，不能证明队伍实际提交的完整附件一定没有更多实现。
