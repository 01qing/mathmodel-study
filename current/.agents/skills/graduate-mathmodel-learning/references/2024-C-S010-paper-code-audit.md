## Q1 波形识别

论文采用统计特征和几何特征两条线：峰度等统计量、FFT 前 k 大频率/幅值、二阶导数非零数量，再用决策树和随机森林做重要性，决策树/RF/逻辑回归在两套特征上形成 6 个分类器并投票。

值得学习：特征具有信号几何解释，论文还主动提醒 100% 分类可能来自数据高度可分或样本简单。

需要审计：正文中 s5 与 s4 的 Spearman 系数写为 `0.1`，却解释为“极强正相关”，附近两个相关系数又约为 0.909/0.907，存在明显数值/文字漂移。打印附录只展示局部 FFT 提取，没有最终六模型投票实现。随机行/普通交叉验证也不能证明跨材料/温度/频率迁移。

## Q2 温度修正 Steinmetz

论文提出 6 个温度修正假设，从温度主效应到温度与 log f/log Bm 的交互项，并用 MSE/R²比较。打印代码对一个材料/正弦波块使用 5 折 KFold，这一点比只做拟合内指标更好。

仍有两点关键边界：

1. KFold 是 `shuffle=True` 的随机行折叠，各折仍混有四种温度，不等价于留一温度验证；
2. 打印代码读取 `train_4.csv`，而正文主要用材料1示例并汇总四材料，说明附录只是局部片段。

正文还把 415.61 写成“最大值”、3616132.54 写成“最小值”，数值大小关系明显颠倒，属于自动算术/叙述 sanity check 应拦截的错误。

## Q3 因素和交互

这是 S010 相比 S009 的明显优点：除了 p 值，还报告偏 Eta²、Cohen's f，并明确保留温度×材料和材料×波形“不显著”的结论。论文也发现 70℃/90℃最优随频率区间改变，并承认随机抽样会影响结论。

仍不能把“按频率排序后抽样”视为完成了协变量控制。频率和 Bm 都直接影响损耗，应优先使用含 `log f`、`log Bm` 的 ANCOVA/稳健回归或调整后边际均值。正文“温度 P<0.05，但变化并不显著”的措辞也混淆了统计显著与实际效应小，应该改成“统计显著、效应量小”。

## Q4 通用损耗模型

论文路线：修正 Steinmetz/等效正弦频率 baseline -> 9 种 ML -> 5 基本特征 -> 加峰度 -> 加 IGSE 先验 -> CatBoost 最优。

这条“物理基线 + 特征消融 + ML”结构值得学习，但打印代码和最终模型不一致：

- 代码计算 `peak_kurtosis`、`peak_skewness` 后没有 append 到 `feature`；
- 可见代码完全没有 IGSE 特征；
- 正文说频率、Bm、温度取 log，代码只 log 温度和频率，`maxB` 原值输入；
- `true_mse` 只是累加平方误差，没有除样本数，实际上是 SSE；
- 正文相对误差表用 0.03542 这类比例，代码则乘100后输出百分数，指标尺度需统一；
- 随机 `train_test_split` 只能代表同分布留出，不能支撑“跨材料/工况通用”的强结论。

以后遇到“物理先验特征/模型堆叠”，必须追踪 `计算 -> 列 -> X -> 最终模型 -> 推理` 数据流，并说明物理先验的参数是否由训练折内拟合，避免目标泄漏。

## Q5 优化

论文把磁芯损耗和 `f*Bm` 组合为 1:1 加权目标，比较 GA/PSO/GWO，并声称 GWO 最优；随后列出不同材料×波形×温度组合结果。

主要门禁：

1. 损耗和 `f*Bm` 单位/尺度不同，原始值 1:1 并不等于偏好 1:1；需归一化/无量纲化或 Pareto/epsilon-constraint。
2. EMI 定义为 `loss/(loss+energy)`，这是损耗占比，越小越好，却称“效率最大化指标”，名称/方向不一致。
3. 打印附录只有 PSO，没有 GA/GWO，不能从附录复核“GWO最好”。
4. 可见 PSO 示例固定 `t=25, x=3, y=1`，并非正文主报告的 90℃/正弦/材料4；可能作者另有循环，但打印片段未展示。
5. 更严重的是类别编码：Q5 helper 期望整数类别，但 objective 先用字典映射成中文字符串再送入 helper。对 3 种波形和 4 种材料做精确自包含烟测后，全部 legal categories 都得到全零 one-hot。这意味着可见优化片段中的类别信息被擦除。
6. Q5 重新训练的是五基本特征 CatBoost，不是 Q4 最终 IGSE 增强 CatBoost，部署模型身份发生回退。
7. 随机优化器比较需要相同目标调用预算和多 seed 分布，不能只比一个最好点。

## 图表学习

正文显式识别 32 个图题、33 个表题。可迁移的证据顺序主要是：

- Q1：原波形 -> FFT/特征 -> 特征重要性 -> 相关性 -> 分类结果；
- Q2：3D 数据分层 -> baseline -> 多轮修正假设 -> 误差比较；
- Q3：分布假设 -> 主效应/交互 -> 热力图 -> 频率依赖的最优条件解释；
- Q4：变换诊断 -> model×feature ablation；
- Q5：算法流程 -> 多算法/多组合结果。

建议升级：Q4 用同一冻结 split 的消融矩阵 + 跨工况验证；Q5 用重复随机种子箱线图/Pareto/权重敏感性/类别编码契约图，而不是只画算法示意图。
