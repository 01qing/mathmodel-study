# 2024-E S018 论文—代码联合审计

## 范围

- 论文：E24102870008《高速公路应急车道紧急启用模型》，81 页。
- 当前证据：全文文字层、图表标题/上下文、67–81 页打印附录代码。
- 未拥有：原视频、作者完整工程、训练权重、派生数据、原 PDF 像素，因此不宣称端到端复现或精确视觉风格学习。

## Q1

论文构造 YOLO/OpenCV → 交通流参数 → TPI → CNN/TCN-SVR/BiGRU-attention → 实时预警链。值得保留的是跨视频验证方向和完整系统分解。需要修复：

1. 表2显示视频约 10 倍速。25 fps 时 1 帧约 0.04 视频秒、0.4 实际秒；25帧是约10实际秒。所有 veh/s、预警提前量、横轴都必须恢复真实时钟。
2. 正文/表头多处写 25帧聚合，但附录计数代码在 `cart==33` / `frame_time==33` 时写记录。
3. 时间窗 unique vehicle count 除以 30m 不能自动视作同时空间密度。
4. 论文称 6层1D-CNN、TCN自适应SVR、PSO、BiGRU和多头注意力；附录只看到较小 CNN-BiGRU-attention 片段，且 recurrent 输入被 reshape 成单 timestep，attention 引用未定义 `W`，未见完整 TCN-SVR/PSO、多头注意力训练链。
5. 正文预警规则含窗口均值条件 + 梯度>1.3，附录仅见梯度>0.85。
6. 表8点4 `RMSE=0.1652` 与 `MSE=0.2164` 不满足 `MSE=RMSE^2`；前者平方约0.02729。

## Q2

Weibull/MLE 容量分布思路适合做可解释阈值，但阈值证据链未闭合。摘要是 `speed<20 OR flow>0.5`，Q3 实时决策文本是 `speed<threshold AND flow>threshold`；正文还将 `<15` 作为拥堵、`>20` 作为非拥堵，15–20 未定义状态。附录“问题2”大段为 ResNet/Mask-RCNN/FPN/RPN 视觉代码，不是 Weibull/MLE 阈值实现。

## Q3

时空安全约束的思路值得保留，但“开启后”点4结果来自点2开放状态数据训练的响应模型，是跨站点 transferred counterfactual，不是点4真实干预。需要做协变量支持/效应稳定性验证。表9速度提升百分比也应机器复算：8.16→18.73 标准增长约129.53%，11.76→18.61约58.25%。Eq.(47)还把 `T_ET`（前文定义为总碰撞暴露时间）放进平均通行时间公式，符号语义需修。

## Q4

Kriging+GA 可作为布点优化候选，但当前声明变量 `E_i` 是应急车道开闭状态，而题目要求摄像头数量/位置，决策变量与交付量不一致。论文称三个目标归一化后加权，但公式未显式归一化、未给数值权重；也未见 Kriging DOE、holdout surrogate error 或最终候选回原模型验证。0.8km/1.3km 两个位置因此无法从当前附录重放。

## 可迁移门禁

- 双时钟：视频时间/真实时间。
- flow、occupancy、density 分离。
- `T>1` 才允许 RNN 时序记忆论证。
- RMSE/MSE、百分比等自动 replay。
- 所有阈值只来自一个 state-machine registry。
- 跨站点干预必须做 transportability。
- 布点变量必须直接编码位置/数量。
- surrogate 优化前先验证 surrogate，最优候选回原模型复算。
