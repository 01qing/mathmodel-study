# 2024-B S008 论文—代码一致性审计

## 结论边界

S008 已完成 69/69 页全文文字层精读和打印附录代码静态审计。当前工作区没有原 PDF 像素和作者原始工程，因此不能声称像素级版式已学习，也不能声称作者代码已完整复现。

## Q1：seq_time 预测

论文比较随机森林和深层 LSTM。随机森林路径先划分再由 Pipeline 拟合预处理，结构上较安全。LSTM 路径却先对全体数据拟合预处理器，再做 train/test split，存在预处理泄漏；随后把每行 reshape 为 `(samples, 1, features)`。这里的时间步长度为 1，因此虽然调用了 LSTM 层，但没有真实历史序列供循环状态学习，不能把性能归因于“长期依赖”或“时序记忆”。

**Skill 门禁：** 循环模型必须显式给出序列实体、顺序和 `T>1` 的窗口；`T=1` 自动降级为非时序深层模型，并与 MLP/树模型公平比较。

## Q2：PHY Rate 与 (MCS,NSS)

打印代码中，多干扰 SINR 直接执行 `rssi_0 - rssi_1 - rssi_2`。RSSI 为 dBm，对数功率不能这样相减来实现多个干扰源的功率叠加。正确流程应将每个 dBm 转为 mW/W，在该域求和后再计算 SINR。

论文再用 PHY Rate 反推 `(MCS,NSS)`。表中存在重复 PHY Rate，例如 17.2、34.4、51.6、68.8、103.2 等可对应不止一个组合，因此该逆映射不是单射。打印代码通过排序后的“最后一个不大于预测值的条目”解决并列，本质上由表顺序决定，而不是由观测证据唯一确定。

**Skill 门禁：** 多干扰功率先回线性域求和；非单射目标不得通过任意顺序反演，优先直接联合预测合法 `(MCS,NSS)` 对或增加能够消除歧义的约束。

## Q3：吞吐量

论文提供了有价值的机理基线：

`throughput ≈ PHY Rate × (1-PER) × seq_time / test_dur`。

这类问题应先报告物理公式基线，再判断机器学习是否在独立实验组上带来稳定残差改进。S008 的训练证据使用真实 `seq_time`/PHY 相关中间变量，而实际部署阶段会使用 Q1/Q2 的预测中间变量，因此存在 oracle-intermediate 与 deployment shift。安全的级联应使用 OOF 上游预测训练下游，并在 untouched groups 上整链评估。

此外，论文表中报告 3AP polynomial-SVR `MSE=12.48, MAE=7.30`。同一误差向量必须满足 `MSE >= MAE^2`，但 `7.30^2=53.29 > 12.48`，所以至少一个数字或标签有误。该结果不得直接用于模型排名。

**Skill 门禁：** 论文导出前对 MSE/MAE/RMSE、比例、概率、混淆矩阵派生指标和约束量做代数/守恒 sanity check；失败时先修结果，不进入选模和结论。
