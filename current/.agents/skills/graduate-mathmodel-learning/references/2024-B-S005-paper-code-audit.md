## Q1：seq_time 与随机森林

正文描述了按每棵树预测误差分配权重的加权随机森林；可见附录主代码使用 sklearn `RandomForestRegressor(n_estimators=200)` 与内置 `feature_importances_`，未展示树级自定义聚合。因此只能记作“论文声明的加权 RF 在打印代码中未得到实现证据”。

特征重要性只能解释预测关联，不自动构成因果影响率。后续同类题应使用 grouped fold 稳定性、permutation importance/SHAP 作为补充，并保持因果措辞克制。

## Q2：RSSI、SINR 与 (MCS,NSS)

正文明确指出一个样本的 SINR 与同一实验中的其他样本有关。这说明独立抽样单位不是“单行”，而是实验/会话组。验证必须先按 experiment/session 分组切分，再在训练组拟合插补、缩放、插值参数或阈值。

RSSI、噪声和干扰以 dBm 表示时，求和必须转换到线性功率：`P_mW=10^(P_dBm/10)`；计算 `S/(I+N)` 后才可转 dB。

若先预测 PHY Rate 再反推 `(MCS,NSS)`，必须检查映射是否单射；若一个速率对应多个组合，标量预测正确并不推出组合唯一正确。

打印分类代码中还出现 `softmax -> CrossEntropyLoss`，这违反 PyTorch 常规输入契约；CrossEntropyLoss 应接收 logits。

## Q3：吞吐量回归

正文用“95%以上准确率”描述连续值回归，并同时说明平均误差约 5%。此处应改为明确的回归证据：MAE/RMSE/R2（适用时）、绝对/相对误差 P50/P90/P95、以及 `|relative error|<=5%` 之类的阈值覆盖率。

## 通用门禁

1. 独立样本单位先于随机切分。
2. 预处理 fit 只发生在训练组。
3. dBm 不在对数域做功率和。
4. 中间物理量到最终标签先验证可识别性。
5. 连续回归不使用未定义 accuracy。
6. 模型输出域必须与 loss API 契约一致。
7. 论文声明的创新组件必须定位到执行代码；打印附录缺失时标记 evidence gap。
