# 2024 A 同题方法选择：S001 vs S002

不要把同题优秀论文当作两套都要照搬的方案。逐问选择更匹配的数据结构和验证条件的方法。

- Q1：S001偏显式流式状态；S002偏滑动窗近似。先做 exact rainflow 基线和边界序列测试。
- Q2：S001是低参数机理/滞后回归；S002是物理特征+BiLSTM。任何时序模型必须先按时间/原文件划分，再做窗口与归一化。
- Q3：S001 DDPG；S002 NSGA-II。优先用显式优化器作为小规模/离线金标准，再判断是否需要学习型在线策略。
- Q4：先区分噪声、延迟、缺失，再分别验证检测/重构层，最后验证下游优化。

2. 总量平衡不能替代逐实体约束检查。

4. SNR等指标先核对定义与实现，再解释改进。
5. 论文表格可直接复算的比例、平均值和差值必须自动复核。
