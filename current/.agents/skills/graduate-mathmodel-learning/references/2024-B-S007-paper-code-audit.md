## Q1

正文结果实际比较 9 种回归模型，而摘要写“八种”。打印代码将多个实验 CSV 合并后按行 `train_test_split`，没有保留 loc/nav/原实验文件的 group 边界。对 WLAN 同一实验的关联行，这种验证会把相近环境同时放进训练和验证。

CDF 代码把第 90 百分位相对误差 `error_90` 变成 `1-error_90/100` 并命名 `model_accuracy`。这可以作为题目自定义精度口径，但不能与标准分类 Accuracy 或一般回归“准确率”混同。推荐直接报告 P50/P90/P95 相对误差和容差覆盖率。

## Q2

这一篇有一处应明确保留的优点：`calculate_sinr` 对自身 RSSI、各干扰 RSSI 和噪声底都先由 dBm 转为 mW，在线性功率域完成求和与比值，最后再 `10 log10`。这符合功率计算量纲，比直接在 dBm 上相减/相加更可靠。

但其输出结构仍有两个问题：

1. MCS 和 NSS 用两个独立随机森林分别训练、分别切分，重组后没有合法 `(MCS,NSS)` tuple 约束或 joint exact-match 验证。
2. NSS 的 Accuracy 接近 0.984–0.988，而 F1/Precision/Recall 只有约 0.33–0.55。这个组合不是“数据更平衡”的证据，恰恰是多数类主导的强警报。

正文声称比较 8 个分类模型，但可见打印预测附录只给出了 RF 最终路径；因此八模型对比的代码证据保持为 `visible appendix evidence gap`。

## Q3

Q3 使用题目提供的真实 MCS/NSS 查 PHY rate，这避免了把 Q2 预测误差级联进吞吐量模型，作为直接基线是合理的。

但 RSSI 处理仍需修正：正文公式直接对多个天线 RSSI 求和，代码对天线/干扰 RSSI 的 dBm 值做算术平均。若目的是聚合接收功率，应先转线性功率域；若只是统计描述符，必须明确“dBm 均值”而不是“总接收功率”。

另一个严重的一致性问题是结果数字漂移：摘要 Q3 的 2AP 指标完全复用了 Q1 的 `10.412 / 1.756 / 0.064`；Q3 自己的结果表却给出 RF `1.926 / 0.894 / 0.051`、XGBoost `2.144 / 0.923 / 0.052`，随后正文解释又重新写回 Q1 的数值。新 Skill 因此要求摘要、表格、正文、代码输出由同一结果 registry 自动校验。

## 可迁移组合

对新的 WLAN/无线链路题，优先组合三篇训练论文各自可靠部分：

- 从 S007 借 SINR 的线性功率域计算；
- 从 S006 借联合 `(MCS,NSS)` 标签结构，但去掉其泄漏式过采样/编码；
- 从 S005/S006/S007 共同保留可解释树模型作为基线；
- 全部改成 experiment/session group holdout；
- 对类别不平衡使用训练折内 class-weight/resampling，并报告 macro/balanced/per-class 指标；
- 对吞吐量回归报告 MAE/RMSE/R² + P50/P90/P95 误差，不用无定义“accuracy”。
