# 2024-C S011 全文与打印附录审计

## 证据边界

已覆盖 S011 71/71 个文本页，并审计物理页 57–71 的打印 Python 附录。当前工作区没有该论文原 PDF 像素和作者原始工程/官方附件，因此不声称像素级版式学习或端到端作者代码复现。

## Q1

路线为时域/频域/PCA 特征 → K-W/Mann-Whitney 差异筛选 → 峰值因子+峰度 → SVM/决策树/Stacking。三模型均报告 100%。优点是特征解释清晰；风险是可见文字没有证明标签驱动的特征筛选嵌套在 CV 折内，也没有按材料/频率/Bm 工况做 grouped stress test。

## Q2

路线为 Steinmetz 基线 + 五类温度修正，比较最小二乘、模拟退火、PSO 和动态 PSO。打印附录确实有动态 PSO 更新，但没有完整数据/目标函数路径。修正前后 R2 提升主要是同一温度支持上的拟合/选模证据，不是 unseen-temperature generalization。

## Q3

单因素箱线图和 K-W 检验是合理描述，但将两因素交叉均值/方差直接称为“协同效应”不成立。协同/交互必须显式估计 interaction term，并调整频率、Bm 等强连续驱动量。90℃+正弦+材料4是原始数据上的低均值组合，不是调整后的全局最优。

## Q4

正文声称“特征权重提取的双向 LSTM”，但打印程序 2 只实例化三层 Conv1d 与 Linear，没有 LSTM/BiLSTM，也没有独立特征权重模块。正文称最终为 10 维输入，而该程序写死 input_size=1033。criterion 声明 MSELoss，训练却使用 1-R2 的自定义损失。故打印代码不能作为所声明最终架构的实现证据。随机 IID 测试集上加入 0.1 高斯扰动只能称局部扰动鲁棒性，不能替代跨材料/温度/工况泛化。

## Q5

S011 的优点是保留了 Pareto 思路，并明确 Pareto 前沿后还需偏好选点。但实现证据存在四个硬问题：

1. 将权重 a 本身作为决策变量，相当于让优化器自己选择决策偏好；应固定/扫描外部偏好，或先保留 Pareto。
2. 正文说先归一化，但式(8.3)未展示归一化。按显示的 raw 公式重算，GA 为 69.425101、PSO 为 11.249049，与表 8.2 的 4.6918/30.8623 不一致。
3. MOPSO 示例 Bm=0.4261 超出上界 0.3133，另一例 f=49910 低于下界 50000。终稿前所有 Pareto 点必须 replay constraints。
4. 打印附录到页末没有 Q5 GA/PSO/NSGA-II/MOPSO 代码，因此不能从可见实现验证算法排名。

另外，“NSGA-II 点更集中，所以优于 MOPSO”不是充分的多目标算法证据。应在相同预算、多随机种子下比较 hypervolume、IGD/GD、spread 和可行率。

## 可迁移组合

对新题，保留 S011 的“物理修正族比较”和“Pareto 而非强行单一点”思路，但必须叠加：leave-condition-out 选模、显式 interaction+协变量、代码层架构核验、混合离散变量完整搜索、目标尺度/偏好分离、Pareto 可行性 replay。
