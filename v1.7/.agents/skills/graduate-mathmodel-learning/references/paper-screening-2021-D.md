# 2021 D 优秀论文筛选与首组对照

## 结论

第一组主对照论文锁定为：

1. `D21102700119.pdf`，上海师范大学
2. `D21104860088.pdf`，武汉大学

选择依据不是“奖项最高”，而是：

- 正文可完整核对；
- 四问方法链均可追溯；
- 两篇路线差异足够大；
- 都有验证设计，同时也暴露出可讨论的风险；
- 适合训练“为什么选这个模型、为什么不选另一个模型”。

## 一、论文 A：D21102700119

### Q1
`LASSO + Pearson + Random Forest + Mutual Information`
→ 各取前40
→ 加权投票
→ 高相关滤波
→ 20个变量。

核心价值：同时覆盖线性关系、非线性关系和模型重要性。

### Q2
HGBRT 为主模型，并与 SVR、MLP、RF 等比较；
使用 K 折交叉验证和网格搜索调参。

### Q3
HGBCT；
针对类别不均衡设置小类别惩罚因子；
与 SVM、RF、MLP、AdaBoost、DecisionTree 比较。

### Q4
HGBRT + HGBCT 形成双目标；
NSGA-III 搜索；
引入 λ 表示活性/药性偏好。

### 最值得质疑的地方
1. 类别不均衡下仍主要用 Accuracy 评价。
2. 把 ADMET 组合人工赋成 10/8/5/2/1/0，效用尺度存在人为性。
3. 在描述符 min-max 范围内直接优化，不等于得到化学上可实现的真实分子。
4. 论文自己承认“变量独立”是假设，可能忽略物理化学耦合。

## 二、论文 B：D21104860088

### Q1
数据清洗和相关性筛选后：
- Random Forest 内置重要性
- Permutation importance
- SHAP

三种重要性共同分析，再取20个变量。

### Q2
比较12类回归模型；
LightGBM 最优；
再用 SHAP 与随机森林的重要变量交叉检查；
GridSearchCV 调参。

### Q3
每个 ADMET 标签单独建模：
- WOE / IV 做变量筛选
- 过采样处理不均衡
- 13种分类模型竞争
- Caco-2 / CYP3A4 / hERG 选 XGBoost
- HOB / MN 选 RandomForest
- 10折交叉验证

这一点特别适合作为 Skill 的“禁止五个标签强行共用一个算法”的教学案例。

### Q4
先用 PSO 得 Pareto 解集；
再用主要目标法/目标规划思路交叉验证；
最后给出描述符取值范围。

### 最值得质疑的地方
1. 必须核对过采样发生在训练折内部还是交叉验证之前，否则可能数据泄漏。
2. PSO 自己被论文指出可能陷入局部最优且对参数敏感。
3. 与论文A相同，描述符空间的最优组合不自动等于真实可合成分子。
4. 模型数量很多，必须避免“算法越多越好”的误导。

## 三、为什么这两篇适合作为一组

| 问题 | D21102700119 | D21104860088 | 教学冲突点 |
|---|---|---|---|
| Q1 | 四方法投票 + 高相关滤波 | RF/Permutation/SHAP | “投票融合” vs “可解释性重要度” |
| Q2 | HGBRT | LightGBM | 同属提升树但选择流程不同 |
| Q3 | 一个 HGBCT 框架处理5标签 | 每个标签单独竞争模型 | “统一模型” vs “标签定制” |
| Q4 | NSGA-III + 人工效用权重 | PSO + 主要目标法复核 | 两种多目标求解哲学 |
| 验证 | K折 + Accuracy为主 | 多指标 + 10折CV | 分类评价是否充分 |
| 风险 | 人工效用标度明显 | PSO局部最优/泄漏检查 | 优化风险不同 |

## 四、Skill 应该学到什么

不要记成：

> 2021 D 应该使用 HGBRT / LightGBM / XGBoost。

应该记成：

1. 先识别任务是高维变量筛选、回归、多标签二分类和多目标/约束优化。
2. 特征筛选要同时考虑预测贡献、冗余和稳定性。
3. 回归模型必须通过同一数据切分或嵌套交叉验证公平比较。
4. 五个 ADMET 标签不应默认共用一个模型。
5. 类别不均衡不能只看 Accuracy。
6. Q4 最难的不是“用哪种智能优化算法”，而是：
   - 优化变量是否合法；
   - 目标函数怎样定义；
   - 约束是否有化学意义；
   - 最优描述符组合是否可实现。
7. 优秀论文是候选解法证据，不是标准答案。
